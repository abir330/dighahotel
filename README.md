## 🌟 Overview

**Hotel Dollhouse** is a premier boutique budget-luxury hotel nestled in the peaceful, family-friendly **Barrister Colony** of Old Digha, West Bengal. 

This repository houses the complete, production-ready official website engineered with high-conversion aesthetics inspired by **Taj Hotels & Resorts** and **Samero Agency**.

---

## ✨ Key Features

- **🏛️ Coastal Luxury Aesthetic:** Warm ivory canvases (`#FAF8F5`), royal heritage navy (`#0F2236`), and refined champagne gold accents (`#C59B27`) paired with Cinzel serif typography.
- **📸 High-Performance Dual-Format Visuals:** 30 high-resolution photo assets rendered in both modern next-gen **WebP** and progressive **JPEG**, served with `<picture>` tags for sub-second load times.
- **🛏️ Rooms & Suites Catalog:** Complete room showcase with pricing, amenities, room specifications, and instant WhatsApp booking generator.
- **🗺️ 20 Digha Attractions Guide:** Comprehensive local sightseeing guide covering Old Digha Sea Beach, Biswa Bangla Park, Marine Aquarium, Mohona Watchtower, Digha Science Centre, Amarabati Park, and more.
- **🖼️ Modal Lightbox Gallery:** Interactive categorized gallery (All, Rooms, Property, Beach) with keyboard navigation and fullscreen zoom.
- **📍 Location & Directions:** Embedded Google Maps with one-click navigation links and transit details from Digha Railway Station.
- **⚡ SEO & AEO Optimized:** Extensive Schema.org JSON-LD structured data (`Hotel`, `FAQPage`, `BreadcrumbList`, `PostalAddress`, `GeoCoordinates`), OpenGraph meta tags, and local search signals.
- **📱 Creator Click-Down Menu:** Custom "Made by" brand dropdown directly integrated beside the logo featuring developer Abir Ghosh and direct link to [@abir.pov](https://www.instagram.com/abir.pov/).

## 🚀 Running Locally

You can run this project locally with any static web server:

### Using Python:
```bash
# Python 3
py -3 -m http.server 8080
# Or:
python -m http.server 8080
```
Then visit **[http://localhost:8080](http://localhost:8080)** in your browser.

### Using Node.js (npx):
```bash
npx serve .
```
